# System Analysis and Design: DriverPass

Requirements and system design for **DriverPass**, a fictional driver-training company that wants an online system to help students pass the DMV driving test. The system covers online classes and practice tests, lesson scheduling with drivers and vehicles, and account management for five types of users.

## Design highlights
- A web-based, cloud-hosted system, so the client doesn't have to manage servers, backups or security patches
- Role-based access for the owner, IT officer, secretary, drivers and customers
- An activity log on every reservation change, so the owner can trace who made or canceled a booking
- UML models built with «include» and «extend» relationships, so shared behavior is defined once
